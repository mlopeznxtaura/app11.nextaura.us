The Transformer (2017) — in plain English

The original Transformer is a sequence model that removes recurrence (no RNN/LSTM). Instead of reading words one at a time, it processes the whole sequence in parallel using self-attention: for every token, it builds a weighted blend of all other tokens’ values and learns which words matter most to each other. Multi-head attention runs several independent attention patterns at once so the model can capture different kinds of relationships. Because everything is processed at once, word order is injected with fixed sinusoidal positional encodings. The stack has encoders (self-attention + feed-forward) and decoders (masked self-attention, cross-attention, feed-forward).

Core math

1. Scaled dot-product attention

\[ \text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V \]

\(Q, K, V\) = query, key, value matrices. \(d_k\) = key dimension (scaling prevents vanishing gradients).

2. Multi-head attention

\[ \text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\ldots,\text{head}_h)W^O \]
\[ \text{where }\ \text{head}_i=\text{Attention}(QW_i^Q,\ KW_i^K,\ VW_i^V) \]

3. Positional encoding (sinusoidal)

\[ PE_{(pos,\,2i)}=\sin\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right) \]
\[ PE_{(pos,\,2i+1)}=\cos\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right) \]

4. Position-wise feed-forward

\[ \text{FFN}(x)=\max(0,\ xW_1+b_1)W_2+b_2 \]

5. Residual + layer norm (post-LN block)

\[ \text{Layer}(x)=\text{LayerNorm}\bigl(x+\text{SubLayer}(x)\bigr) \]
NextAura novel recipe

From parallel attention to sequential generation

The vanilla Transformer sees the whole sequence at once. To generate left-to-right, we add a causal mask — a “peek-proof shield” on the scores \(QK^\top\): future positions get \(-\infty\), which softmax turns into 0% weight. Token “dog” can look at earlier context but is blocked from “bites” if that word comes later. That forces autoregressive, word-by-word output.

  • The tradeoff: parallel training on GPUs is extremely fast; strict one-token-at-a-time recurrence (classic RNN style) is slow.
  • RPT / Huginn-style recurrent depth: a linear hidden state reads left-to-right, compresses context into a compact memory vector, and passes it forward — human-like sequential reading with modern GPU throughput. Tunable num_steps at test time scales compute without changing weights (Huginn-0125).

Teaching geometry, binary, and language — not just text

  • A. Binary / discrete logic: LLMs live in continuous probabilities (0.83), not CPU bits. We teach discrete reasoning by tokenizing the world — grids, voxels, symbol sequences. “2+2=4” is next-token prediction over patterns, not hardware arithmetic.
  • B. Geometry via tokenization: ViTs chop images into 16×16 patches and treat them like words. 3D uses point clouds or voxels the same way. RoPE (Llama 3+) rotates position embeddings so relative spatial moves (e.g. rotate “car” 90°) are encoded in the math.
  • C. World models (Sora, Genie, V-JEPA): don’t drill geometry with equations alone — force the model to predict the next video frame. To survive, it must infer 3D layout, physics, lighting, and motion internally.
  • D. Mixture of Experts + embodied sim: MoE routes some heads to language, some to 2D pixels, some to 3D math. The deepest lever: let the model write code, run it in Unreal/Unity, watch physics fail, and update weights from what happens on screen — embodied AI / sim-to-real (the “GTA 3” path).

Metamorphic Constraint Field (MCF v2) — app11 open-source slot

The Hierarchical Latent Stack (HLS)

MCF v1 failed because FineWeb knobs (batch 768, 24 GB byte target) were applied to V-JEPA metadata rows (~50–200 tokens each). That caused ~23 min dead-time per step. MCF v2 bypasses the text tokenizer for latents: raw scalar vectors are packed 128 frames per block, a Global Context Token (GCT) injects physics constraints, and dual-target loss prevents template memorization. Target is 1.5B tokens (~5.25 GB) for 360M — not the 24 GB byte trap.

1. Latent packing (throughput fix)

Block_input = Concat(x₁…xₙ) where Σ len(xᵢ) ≥ block size · N=128 frames · restores GPU utilization

2. Global Context Token (GCT)

h_GCT = MLP_phys([gravity, velocity, mass]) · Output = Attention(h_GCT, X_frames)

3. Dual-target loss (anti-memorization)

L_MCF = α·L_latent + β·L_scalar · L_scalar = MSE on physical dynamics (velocity, etc.)

4. Continuous physics solver (Stream A braid)

dz/dt = f_θ(z,t,x) ⇒ z_{t+1} = z_t + Δt·f_θ(z_t,x_t)

5. Architecture profile (360M)

17L×960d×15h · block 256 · FFN 3840 · batch 256 · micro 64 × grad 4 · scalar 12d · grad ckpt · flash bf16

Plain English tradeoff: Stop at ~1.5B tokens (Chinchilla ~20 tok/param for 360M). Data: CS2 continuous physics, ego10k manufacturing, sokoban logic.
